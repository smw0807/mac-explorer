# Mac Explorer

윈도우 탐색기 스타일의 macOS용 파일 관리자 (Electron + React)

## 주요 기능

### 탐색

- **폴더 트리 사이드바** — 탐색기처럼 왼쪽에서 폴더 구조를 펼쳐 탐색
- **즐겨찾기 사용자화** — 폴더를 '즐겨찾기' 섹션에 드래그해서 추가, 우클릭으로 제거 (영구 저장)
- **주소창** — breadcrumb 클릭 이동 + 직접 경로 입력 (`⌘L`, `~` 지원)
- **탭** — `⌘T` 새 탭, `⌘W` 닫기, 폴더 우클릭 → 새 탭에서 열기. 탭을 전환해도 탐색 이력과 선택 상태 유지
- **듀얼 패널** — `⇧⌘D` 로 화면 2분할, 패널 간 복사/이동 편리
- **세션 복원** — 탭 구성(경로·듀얼 패널·숨김 파일 표시)을 변경 후 저장하고 재시작 시 복원
- **타이핑 점프** — 목록에서 파일명 첫 글자를 입력하면 해당 항목으로 즉시 선택 이동

### 보기

- **상세 보기 정렬** — 이름 / 수정한 날짜 / 유형 / 크기 컬럼 클릭 정렬
- **아이콘 보기 / 썸네일 그리드** — 툴바 ⊞ 버튼으로 전환, 이미지 파일은 실제 썸네일 표시
- **네이티브 파일 아이콘** — macOS 시스템 아이콘 그대로 표시
- **미리보기** — `Space` 로 이미지·동영상·오디오·텍스트 미리보기 패널
- **Quick Look** — `⌘Y` 로 시스템 미리보기 (PDF·오피스 문서 등도 지원)
- **숨김 파일 표시** — `⇧⌘.`

### 파일 작업

- **잘라내기 / 복사 / 붙여넣기** — `⌘X` / `⌘C` / `⌘V`
- **드래그 & 드롭** — 폴더 행·다른 패널·사이드바로 끌어서 이동, `⌥` 누르면 복사, Finder에서의 드롭도 지원
- **진행률 표시 복사** — 창 하단에서 여러 복사 작업의 진행률 확인·취소. 시작한 탭을 닫거나 듀얼 패널을 해제해도 작업 유지
- **이름 충돌 처리** — 같은 이름이 있으면 둘 다 유지 / 덮어쓰기 / 건너뛰기 / 취소 선택
- **실행 취소** — `⌘Z` 로 이동·복사·이름변경·생성 작업 되돌리기. 실패한 항목은 원인을 해결한 뒤 재시도 가능
- **일괄 이름 변경** — 다중 선택 후 찾기/바꾸기 또는 연번 패턴(`휴가-###`)으로 한 번에 변경
- **ZIP 압축/해제** — macOS 내장 zip/unzip/ditto 사용. 무결성을 검사하고 완료된 결과만 최종 경로에 반영. 서로 다른 폴더의 파일은 공통 상위 폴더 기준 상대경로를 보존하고, 기존 결과는 이름을 바꾸어 함께 유지
- **다음으로 열기** — 기본 앱이 아닌 다른 앱을 골라서 열기
- **삭제는 휴지통으로** — `⌘⌫` 또는 `Delete`

### 검색 · 갱신

- **검색** — 입력 즉시 현재 폴더 필터, `Enter` 시 하위 폴더까지 재귀 검색
- **Spotlight 검색** — `⌘Enter` 로 파일 이름 + 내용을 macOS 인덱스에서 검색
- **숨김 항목 검색** — 숨김 파일 표시 설정을 재귀·Spotlight 검색에도 적용. 검색 중 설정을 바꾸면 다시 검색
- **검색 상태** — 실패와 일부 결과만 표시되는 상태를 구분해서 안내. 기본 재귀 검색은 결과 500개·깊이 8로 제한하며, `node_modules`와 `Library` 내부는 제외
- **자동 새로 고침** — 현재 폴더의 외부 변경을 감시. 감시가 실패하면 중단 안내와 재시도 버튼 표시

## 파일 작업과 복구 범위

복사는 임시 위치에 항목을 완성한 뒤 대상에 반영합니다. 덮어쓰기는 기존 대상을 임시로 보관하고 교체하며, 교체 전 실패·취소 시 기존 대상을 유지하거나 복원합니다. 복구 자체가 실패하면 보관 경로를 오류 메시지에 표시합니다. 원본 폴더의 하위로 복사·이동하거나 다른 선택 원본을 덮어쓰는 작업은 차단합니다.

여러 항목을 복사·이동·이름변경하다 일부만 완료된 경우 완료 항목은 유지하고 실행 취소에 기록합니다. 복사 취소 시 현재 처리 중인 임시 결과를 정리하며, 이미 완료한 복사본까지 삭제하지는 않습니다. 잘라내기 후 이동이 실패하면 미완료 항목은 앱의 클립보드에 남아 다시 붙여넣을 수 있습니다.

다른 볼륨으로 이동할 때는 복사 완료 후 원본을 정리합니다. 원본 정리가 실패하면 완전한 복사본을 보존하고 그 경로를 안내합니다. 이 경우 원본이 일부 남아 있을 수 있으므로 안내된 경로와 원본을 직접 확인해야 합니다. 해당 항목은 자동 실행 취소 대상으로 취급하지 않습니다.

복사 전후 원본과 덮어쓰기 대상의 하위 항목까지 비교합니다. 작업 중 변경이 확인되면 중단하며, 이동 후 원본 정리는 검증한 파일만 삭제하고 빈 폴더만 제거합니다. 정리 중 새 파일이 생기거나 기존 항목이 바뀌면 남은 원본 또는 이전 대상의 보관 경로를 안내합니다. 다른 프로그램의 변경과 파일 삭제 사이를 운영체제 수준에서 원자적으로 잠그지는 않습니다.

일반적인 앱 종료는 새 파일 작업을 차단하고 진행 중인 작업의 완료·취소·복구와 임시 파일 정리를 기다립니다. 강제 종료나 전원 차단에는 이 종료 대기가 적용되지 않습니다.

ZIP 압축 해제는 원본의 안정된 임시 복제본을 검사한 뒤 별도 임시 폴더에 해제합니다. 손상되었거나 해제에 실패한 결과를 완성된 폴더로 남기지 않으며, 기존 출력 폴더는 덮어쓰지 않습니다. 권한 등의 문제로 임시 결과도 정리하지 못하면 남은 경로를 오류에 표시합니다. macOS 격리(quarantine) 속성은 복제·해제 과정에서도 유지합니다. 암호로 보호된 ZIP 해제는 지원하지 않습니다.

실행 취소는 현재 실행 중인 앱의 최근 50개 작업을 대상으로 합니다. 복사·생성 취소는 결과물을 휴지통으로 보내며, 이동·이름변경 취소는 원래 경로와 이름으로 복원합니다. 원래 이름이 이미 사용 중이면 기존 항목을 덮어쓰지 않고 실패를 알립니다. 여러 항목을 되돌리다 실패해도 완료한 항목은 다시 처리하지 않으며, 남은 항목은 다음 `⌘Z`로 재시도할 수 있습니다.

실행 취소는 작업 당시 파일 정보와 현재 항목을 비교합니다. 다른 프로그램이 같은 경로의 파일을 교체·수정하거나 폴더 안에 항목을 추가하면 실행 취소를 중단하여 변경 내용을 보존합니다. 앱 안에서 연속으로 이름을 바꾸거나 이동한 경우에는 각 작업을 역순으로 되돌릴 수 있습니다.

현재 제한은 다음과 같습니다.

- 복사 시 파일·폴더 권한, 접근·수정 시각(atime/mtime), 심볼릭 링크를 보존합니다. ACL, 확장 속성(xattr), 리소스 포크의 보존은 아직 보장하지 않습니다.
- **성공한 덮어쓰기 이전 대상과 휴지통으로 삭제한 항목은 앱의 실행 취소로 복구할 수 없습니다.** 휴지통 복원은 Finder에서 처리해야 합니다.
- 탭을 닫아도 복사는 계속되지만, 앱 창이 닫히면 진행 중인 복사에 취소를 요청합니다. 앱을 다시 실행한 뒤 복사 작업이나 실행 취소 이력을 이어받지는 않습니다.
- Spotlight 결과는 macOS 인덱싱 상태에 따라 달라집니다. 재귀 검색도 제한·제외 폴더·접근 권한 때문에 전체 항목을 포함하지 않을 수 있으며, 이때 일부 결과임을 표시합니다.

## 실행 방법

실행에는 **macOS 13 이상**이 필요합니다(Electron 45 기준).
개발 환경은 **Node.js 24.15.0 이상인 24.x 또는 26 이상**을 사용하세요.

```bash
cd mac-explorer

# 잠금 파일 기준으로 의존성 설치 (권장)
npm ci

# 개발 모드 (핫 리로드)
npm run dev

# 프로덕션 실행
npm run start

# .dmg 배포 파일 만들기 (release/ 폴더에 생성)
npm run dist
```

Electron 42 이상은 처음 실행할 때 플랫폼에 맞는 Electron 바이너리를 다운로드합니다.
처음 `npm run dev` 또는 `npm run start`를 실행할 때는 네트워크 연결이 필요하며 다운로드 시간이 걸릴 수 있습니다.
`npx electron --version`으로 미리 다운로드와 버전을 확인할 수도 있습니다.

첫 실행 시 macOS가 홈/문서/다운로드 폴더 접근 권한을 물어보면 허용해 주세요.
(시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더)

## 검증

```bash
npm run lint          # JavaScript / React 정적 검사
npm test              # 파일 작업·IPC·UI·실행 취소 회귀 테스트
npm run build         # 프로덕션 렌더러 빌드
npm run test:electron # macOS: 실제 Electron과 임시 파일을 사용하는 스모크 테스트
npm audit             # 개발 의존성을 포함한 취약점 검사
```

회귀 테스트는 임시 폴더의 파일과 모의 Electron IPC, jsdom UI를 사용합니다. ZIP 내용 검증은 `zip`·`unzip`이 있을 때 실행하며, 대소문자 별칭 검증 등 파일시스템에 의존하는 테스트는 지원 환경에서 실행합니다. `test:electron`은 독립된 임시 프로필로 미리보기·파일 작업 중 종료·취소 버튼의 Enter·설정 변경 직후 닫기와 저장 실패 후 재시도를 확인합니다. 전체 화면 조작이나 두 아키텍처의 배포 검증을 대신하지 않습니다.

CI는 macOS와 Linux에서 정적 검사·회귀 테스트·빌드를 실행하고, 실제 Electron 스모크 테스트는 macOS에서 실행합니다. Linux 검사는 macOS 전용 앱의 배포 지원을 의미하지 않습니다. DMG 배포 전에는 macOS에서 `npm run dist`로 arm64·x64 패키징도 확인하세요.

Electron은 개발 의존성으로 설치되지만 배포 앱의 런타임이기도 합니다. 따라서 `npm audit --omit=dev` 결과만으로 의존성 점검을 마치지 않습니다. 의존성을 변경한 경우 잠금 파일을 함께 갱신하고 위 검증을 다시 실행하세요.

## 설정과 오류 안내

세션·즐겨찾기는 Electron의 `userData` 경로에 저장됩니다. 패키징된 앱의 기본 위치는 `~/Library/Application Support/Mac Explorer/settings.json`이며, 개발 실행에서는 앱 이름에 따라 달라질 수 있습니다. 읽을 때 저장 구조를 검증하며, 손상되었거나 유효하지 않은 설정은 기본값 또는 유효한 항목만 사용합니다. 저장은 임시 파일 작성 후 교체하여 쓰기·교체 실패 시 기존 파일을 보존합니다.

설정 변경은 순서대로 저장하며, 실패하면 화면의 안내에서 재시도할 수 있습니다. 창 닫기와 정상 앱 종료는 마지막 탭·경로·듀얼 패널·숨김 표시·즐겨찾기 저장을 기다립니다. 저장에 실패하면 창을 유지합니다. 강제 종료나 전원 중단까지 마지막 변경의 저장을 보장하지는 않습니다.

자동 새로 고침이 중단되면 해당 패널의 안내에서 **재시도**를 누르거나 `⌘R`로 목록과 현재 검색을 다시 요청할 수 있습니다. 파일 작업 후 관련 검색과 펼쳐진 폴더 트리가 갱신되며, 트리는 다시 펼칠 때도 재조회합니다. 폴더 자체를 읽지 못한 오류와 검색 실패는 화면에 따로 표시합니다.

정상 앱 종료는 진행 중인 파일 작업의 완료·취소·복구를 기다립니다. 복사·이동·덮어쓰기 도중 원본이나 대상의 변경을 감지하면 해당 항목을 보존하고 오류를 알립니다. 정리를 완료하지 못한 경우에는 남은 원본·백업·임시 폴더의 위치를 오류에 표시합니다.

실행 취소는 앱이 기록한 파일 상태와 현재 상태가 일치하는지 확인합니다. 외부에서 편집하거나 다른 파일로 교체한 항목, 새 하위 항목이 생긴 폴더는 자동으로 삭제·이동하지 않습니다. 실행 취소 기록은 현재 창의 실행 중에만 유지되며, 휴지통 이동과 덮어쓰기 전 대상의 복원은 지원하지 않습니다.

## 구조

